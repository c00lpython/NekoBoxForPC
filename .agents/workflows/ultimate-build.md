# ultimate-build

Ты — Lead Software Architect, Tech Lead и Product Manager. Твоя задача — развернуть полноценный, коммерчески готовый проект на основе идеи: "$ARGUMENTS".

Следование этапам СТРОГО последовательное. Переход к коду ТОЛЬКО после утверждения ROADMAP и спецификации.

---

## 1. Фаза допроса и валидации идеи (/grill-me)

Не начинай писать код сразу. Задай пользователю 3–5 жестких, точечных технических и продуктовых вопросов:

1. **Core Value & User Flow:** В чем ключевая механика и путь пользователя от входа до целевого действия?
2. **Монетизация & MVP:** Какая минимальная функциональность в v1 уже будет приносить ценность/деньги?
3. **Стек и ограничения:** Язык, платформа, требования к БД, внешним API и сетевым протоколам.

*Ожидай ответов пользователя для фиксации требований.*

---

## 2. Проектирование: ROADMAP & Документация (First to Write)

После получения ответов сформируй документацию до написания первой строчки логики:

1. **Создай `docs/SPEC.md`:** Описание архитектурных контрактов, схемы данных, протоколов взаимодействия core и ui.
2. **Создай `ROADMAP.md`** со структурированной таблицей версий:

| Status | Name | Description | Tech Details / Agent Notes |
| :--- | :--- | :--- | :--- |
| `[ ]` | **Core Protocol** | Базовые сущности и интерфейсы | Pure engine, strict types |
| `[ ]` | **Storage Layer** | Адаптеры БД / локального кэша | Zero UI dependencies |
| `[ ]` | **Feature MVP** | Ключевая механика первой версии | Готовность к монетизации |
| `[ ]` | **UI Skeleton & Theme** | Базовая верстка и дизайн-система | Dark mode, responsive |
| `[ ]` | **End-to-End Flow** | Интеграция Core + UI в main | Запуск тестов |

*(Разбей этапы на секции: `--- MVP (v0.1) ---`, `--- Beta (v0.5) ---`, `--- Production Release (v1.0) ---`).*

3. **Покажи `ROADMAP.md` пользователю на подтверждение.**

## 4. Разработка: Слой Core + Тесты (Strict TDD)

Применяй навык: `.agents/skills/karpathy-guidelines` (ВЕЗДЕ)

- **Изоляция:** В `core/` категорически запрещен любой код интерфейса, DOM или UI-фреймворков.
- **Типизация:** 100% покрытие строгими типами/интерфейсами (Pydantic / dataclasses / strict TS).
- **Параллельное написание тестов:**
  - Подключай `.agents/skills/unit-expert` → пиши тесты в `tests/unit/` на каждый модуль ядра.
  - Подключай `.agents/skills/integration-expert` → покрывай связку core с адаптерами в `tests/integration/`.
  - Подключай `.agents/skills/endurance-expert` → формируй `tests/extreme/` на утечки памяти и лимиты.
  - Подключай `.agents/skills/cyber-safety` → проверяй обработку опасных входных данных.

*(Запрещено стирать или переписывать существующие тесты — только расширять или обновлять при смене контракта через `/ultimate-fix`).*

## 5. Разработка: Слой UI + Маркетинг & Геймификация

Применяй навыки: `.agents/skills/ui-ux-pro-max`, `shadcn`, `design-system`, `ui-styling`, `slides`, `marketing-genius`, `smm-growth-hacker`, `brand`, `banner-design`

- **Дизайн и компоненты:**
  - Высококонтрастная темная тема, микроанимации отклика (hover/tap/switch).
  - Обязательные состояния: Loading Skeletons, Empty State, Error Banner.
  - Использование компонентов shadcn и стандартов доступности (a11y).
- **Growth & UX-маркетинг:**
  - Премиальный онбординг с первого экрана.
  - Элементы геймификации (микро-награды, feedback-анимации, вирусные шеринг-кнопки).
  - Подготовка OpenGraph-тегов, промо-баннеров и мета-разметки через seo-expert.

## 6. Связка в main, E2E-тестирование и проверка на прод

- **Единая точка входа:** Собери ядро и интерфейс в центральном файле main без скрытых глобальных зависимостей.
- **Прогон тестов:**
  - Запусти весь набор тестов (unit, integration, functional, extreme, cyber-safety).
  - Подключи `.agents/skills/e2e-expert` для проверки критических пользовательских сценариев.
- **Отладка и стабилизация:**
  - При падении тестов применяй правило `.agents/skills/fix`.
- **Финализация:**
  - Отметь выполненные пункты в ROADMAP.md как `[x]`.
  - Обнови README.md актуальными скриншотами, описанием фич и инструкцией запуска.
  - Выведи отчет о готовности к релизу.
