## Steps

### 1. Синхронизация с реальностью
- git status / git log --oneline -10 / git branch
- Убедиться, что нет незакоммиченных изменений, теряющих контекст
- Если есть — сообщить мне, не коммитить самостоятельно

### 2. Проверка целостности
- git grep -l "<<<<<<" "HEAD" — конфликт-маркеры
- python -m pytest tests/unit/ -v — актуальное состояние тестов
- Доложить результат кратко, без домыслов

### 3. Согласование задачи
- Уточнить у меня scope задачи, если он неочевиден из запроса
- Не начинать правки, пока не подтверждён объём

### 4. Работа
- Вносить изменения инкрементально
- После каждого значимого изменения — прогонять релевантные тесты локально

### 5. Перед сдачей
- Полный прогон: python -m pytest tests/unit/ -v
- Явно перечислить, что изменено и что показали тесты
- Не коммитить/пушить без моего разрешения
