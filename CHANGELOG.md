## [1.0.0-beta] - 2026-09-18

### Добавлено (Сборка, CI/CD и автоматизация)
- **Унифицированные скрипты сборки (`build.ps1` и `build.sh`):**
  - Поддержка параметров `core`, `cli`, `app`, `all`, `test`, `help`.
  - Удобная сборка десктопного ядра sing-box (`core`) и менеджера `nbpfpc` (`cli`) в один клик.
  - Поддержка упаковки мультиплатформенных архивов в `release_dist/` (`-Dist`).
- **Единый запуск тестирования (`test.ps1` и `test.sh`):**
  - Комплексный прогон: Python unit-тесты (`pytest`), Rust тесты (`cargo test`), валидация отсутствия маркеров конфликтов слияния git.
- **GitHub Actions Workflows:**
  - `ci.yml`: автоматический прогон всех тестов и тестовая сборка `core` и `cli` при каждом push/PR.
  - `release.yml`: мультиплатформенная матричная сборка релизов под Windows 10/11 x64, Windows 7/8 x64 (static CRT), Linux x86_64 (musl static), macOS ARM64 Apple Silicon, macOS x64 Intel; автоматическая генерация Changelog и публикация GitHub Release.

### Добавлено (CLI `nbpfpc` и TUI)
- **Улучшенный пошаговый мастер `proxychain`:**
  - Последовательный выбор хопов (`Хоп 1 [Входной узел]`, `Хоп 2 [Выходной узел]`, `Хоп 3+`), поддержка UDP и режима редактирования `editconfig`.
- **Интерактивный конструктор правил маршрутизации (`newrule` / `editrule`):**
  - Раздельный интерактивный ввод `SITE:` и `IP:`, умное меню выбора пресетов и автодополнений (`geosite:`, `geoip:`, `ruleset`, `regex`).
- **Спецификация протоколов `protocols.json`:**
  - Полная поддержка всех 14 протоколов sing-box со всеми полями, валидацией типов и дефолтами.
- **Улучшенный поиск в терминале:**
  - Прямой вызов поиска клавишами `/`, `F`, `А` (русская раскладка) и `F3` без перехвата терминала по Ctrl+F.
- **Расширенные режимы замера задержек (`ping` / `-ping`):**
  - Флаг `-m, --mode <table|list|pager>`:
    - `table`: стандартная цветная таблица результатов (по умолчанию).
    - `list`: компактный вывод списка аналогично команде `list` с отметкой активного узла `* [PICKED]` и цветным отображением миллисекунд.
    - `pager`: запуск полноэкранного TUI-пейджера по свежим результатам замера с поиском по нажатию `/`.
  - Флаг `-s, --sort <fastest|slowest|name|group|original>`:
    - `fastest` (или `asc`): от самых быстрых к медленным, таймауты в конце.
    - `slowest` (или `desc`): от самых медленных к быстрым, таймауты в конце.
    - `name` (или `alpha`): по алфавитному порядку имен конфигураций.
    - `group`: сортировка по названию группы, затем по имени узла.
    - `original`: сохранение исходного порядка выборки селектора.
  - Автоматическое пакетное сохранение задержек (`update_pings_batch`):
    - Все измеренные задержки теперь сохраняются в `store.json` (поле `last_ping_ms` профилей).
    - Добавлены флаги `--save` (включен по умолчанию) и `--no-save` (для тестовых замеров без сохранения).
  - Экспорт результатов в JSON:
    - Флаг `--export <PATH>`: сохранение детального отчета со сводкой (время, средний пинг, количество таймаутов) и массивом узлов.
  - Поддержка одиночного дефиса для длинных опций в CLI (`-mode`, `-sort`, `-save`, `-no-save`, `-export`, `-threads`).
- **Интерактивное восстановление и режимы слияния (`recovery` / `-recovery`):**
  - Интерактивное окно подтверждения с детальной сводкой перед применением бэкапа (список новых и обновляемых групп/профилей, правил маршрутизации, изменений настроек и баз Geo).
  - Режимы восстановления (`-m, --mode <merge|hard>`):
    - `merge` (по умолчанию): интеллектуальное слияние без удаления существующих данных (новые группы/правила добавляются, существующие обновляются, локальные сохраняются).
    - `hard`: полная замена выбранных компонентов данными из бэкапа (аналог `git reset --hard`).
  - Флаг `-y, --yes` для автоматического подтверждения в скриптах и автоматизации.
- **Встроенные системные пресеты и ассеты (`assets` / `-assets`):**
  - Подкоманды `nbpfpc assets list` и `nbpfpc assets install`.
  - Группа `WARP`:
    - Профиль Cloudflare WARP на базе AmneziaWG 2.0 с заготовленными параметрами обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`-`H4`).
    - Профиль Cloudflare WARP MASQUE (VLESS + HTTP/3 Connect-UDP).
  - Группа `Goida Group`:
    - Предустановленная бесплатная подписка (Free Sub) с интервалом автообновления 12 часов и стартовыми узлами прямого обхода (`Bypass`) и CDN Fallback.
- **Селекторы конфигураций:**
  - Поддержка синтаксиса диапазонов индексов: `[1-3]`, `1-3`, `[1-5]`.
- **Тестовое покрытие:**
  - Добавлены unit и интеграционные тесты для пакетного сохранения задержек `update_pings_batch`, алгоритмов сортировки, предпросмотра и слияния `recovery` (`merge`/`hard`), встроенных ассетов и диапазонов селекторов (`constructor_and_storage_tests.rs`).
  - Разработан автоматизированный E2E PowerShell сценарий `tests/e2e_ping_modes.ps1`.
- **Документация:**
  - Обновлены `docs/CLI_USAGE.md` и `README.md`.
